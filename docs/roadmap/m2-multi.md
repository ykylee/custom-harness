# M2 — 멀티 하네스 · 멀티 세션 (세부 계획 · WBS)

- 문서 목적: [ROADMAP](../ROADMAP.md) M2 의 세부 계획. 1차 타깃 3종 + 멀티 세션 UI + 3 OS 번들로 "제품 형태" 완성.
- 상태: approved (v1, 2026-08-25 사용자 승인)
- 최종 수정일: 2026-08-25
- 진입 조건: M1 수용 통과. **Windows 범위 확정 (2026-08-25 사용자 승인)**: Windows 번들은 **omp 확정 + pi 조건부(실기기 실측 통과 시) + grok 제외** ([Windows 조사](../reference/windows-support.md) 근거). macOS/Linux 는 3종 전부.
- 완료 기준: 3 하네스 × 3 OS 스모크 매트릭스 통과(축소안 반영 범위 내) + 동시 세션 5개 안정 + NFR-3(바인드·토큰)·NFR-9(플랫폼 일관성) 검증 + 설치 스크립트로 무인 설치 성립
