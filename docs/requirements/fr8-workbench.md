# FR-8 상세 — 작업 공간 (터미널 · 파일 · 변경사항)

- 문서 목적: [REQUIREMENTS](../REQUIREMENTS.md) FR-8 그룹의 상세 요구사항. 워크스페이스를 대화창이 아닌 **작업 캔버스**로 만든다.
- 상태: draft (v1, 2026-08-30 — paseo 서비스 분석 승인에 따른 신설)
- 최종 수정일: 2026-08-30
- 근거 문서: [paseo 서비스 구성 분석 §1.3~1.6](../reference/paseo-service-inventory.md)
- 주 단계: M6

## FR-8.1 탭 타깃 일반화 (M, M6)

- 현재 "탭 = 세션"인 구조를 **다형 탭 타깃**으로 일반화한다: `session` / `terminal` / `file` / `diff` / `files`(탐색기) / `new_tab`.
- 탭 ID 는 타깃에서 결정적으로 유도해 같은 대상이 두 번 열리지 않게 한다(이미 열려 있으면 포커스 이동).
- 기존 2분할 페인·레이아웃 복원(localStorage)을 타깃 다형화에 맞춰 확장한다.
- 탭 닫기의 의미를 타깃별로 구분한다: 세션 탭 닫기 = 세션 종료가 아닌 **레이아웃 변경**(세션은 워크스페이스에 남는다).

## FR-8.2 터미널 (M, M6)

- 데몬이 pty 를 소유하고 워크스페이스 `cwd` 에서 셸을 띄운다. 여러 터미널 세션을 동시에 유지한다.
- 렌더러는 기존 WebSocket 을 공유하되 터미널 I/O 는 **바이너리 프레임**으로 보낸다(JSON 인코딩 비용 회피). 터미널 식별자는 프레임 헤더의 슬롯으로 다중화한다.
- 재접속 시 스크롤백을 복원한다. 복원 범위·입력 리플레이 의미론은 feature 플래그로 협상한다(폴백 경로 금지 원칙 유지).
- 크기(cols/rows) 소유권을 명시한다 — 다중 클라이언트가 붙을 때 마지막 활성 뷰 기준.
- 클라이언트 종료와 무관하게 데몬이 프로세스를 유지하며, PID 원장(FR-1)에 기록한다.

## FR-8.3 파일 탐색·열람 (S, M6)

- 워크스페이스 트리 탐색기와 파일 뷰어 탭(읽기 우선, 구문 강조).
- 어시스턴트 응답·툴 카드 안의 파일 경로를 클릭하면 해당 파일 탭이 열린다.
- 외부 에디터로 열기(설정된 명령 실행).
- 대용량 트리는 증분 로딩한다. 파일 감시는 열려 있는 대상에 한정한다.
- 편집·업로드·다운로드는 이번 범위 밖(뷰어까지).

## FR-8.4 변경사항 뷰 (S, M6)

- 워크스페이스의 working diff(미커밋 변경)를 탭으로 열람하고, 변경 발생 시 갱신한다.
- 커밋 diff 열람(해시 지정). 툴 카드의 edit/write 결과에서 해당 diff 로 이동할 수 있게 연결한다.
- diff 스트림은 구독 기반이며, 재연결 시 자동 복원 대상에 포함한다.

## FR-8.5 워크스페이스 스크립트 실행 (S, M6)

- FR-7.5 에 선언된 `scripts` 를 UI/CLI 에서 실행한다. 실행은 **감독 터미널** 위에서 이루어져 출력이 터미널 탭으로 그대로 보인다.
- 실행 상태(대기/실행/종료 코드)를 워크스페이스 단위로 표시한다.
- 장기 실행 서비스·포트 자동 배정·리버스 프록시는 **보류**(별도 판단 후 편입).

## FR-8.6 forge(PR) 연동 — 조건부 (C, 보류)

- 사내 git 호스팅(GitLab/GitHub Enterprise 등) 확인 후 착수. PR 목록·체크 상태·PR 체크아웃 워크스페이스가 대상.
- 선행: 사내 체크리스트 C-2(저장소) 회신.
