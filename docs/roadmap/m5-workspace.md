# M5 — 워크스페이스 모델 (세부 계획 · WBS)

- 문서 목적: [ROADMAP](../ROADMAP.md) M5 의 세부 계획. 세션 위에 **작업 단위**를 세운다 (paseo 도입 웨이브 A).
- 상태: draft (v1, 2026-08-30 — 도입 계획 승인, WBS 는 설계서 승인 후 확정)
- 최종 수정일: 2026-08-30
- 진입 조건: 없음 (M1/M2 완료 선언과 병행 가능 — 사내 협조 대기와 독립)
- 완료 기준: 프로젝트→워크스페이스→세션 3계층이 데몬 정본으로 동작 + 기존 세션 백필 + 사이드바 재편 + 회귀 그린
- 근거: [paseo 서비스 구성 분석 §4 웨이브 A](../reference/paseo-service-inventory.md), [FR-7](../requirements/fr7-workspaces.md)

## 왜 먼저인가

이 모델이 없으면 터미널·파일·diff·위임이 전부 "세션 옆에 매달린 부속물"이 된다. 뒤에 넣으면
세션 귀속·탭 정체성·영속화 경로를 전부 재작업해야 한다. **가장 싸게 하는 방법이 지금 하는 것.**
