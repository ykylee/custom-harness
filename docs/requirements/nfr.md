# NFR 상세 — 비기능 요구사항

- 문서 목적: [REQUIREMENTS](../REQUIREMENTS.md) NFR 그룹의 상세 — 각 항목의 정의, 목표, 검증 절차.
- 상태: approved (v1, 2026-08-25 사용자 승인)
- 최종 수정일: 2026-08-25

## NFR-1 폐쇄망 자기완결 (M — 전 마일스톤 관통)

- **정의**: 설치·기동·세션 실행·업데이트 확인의 전 과정에서 허용 목적지는 ① 게이트웨이, ② (FR-4.6 설정 시) 내부 아티팩트 저장소, ③ localhost 뿐이다.
- **금지 예시**: 하네스 버전 체크·텔레메트리, npm/모델 카탈로그 페치, CDN 자원, Electron 자동 업데이트 체크.
- **검증**: 스모크 테스트 표준 시나리오(설치 → 온보딩 → 하네스별 1턴 코딩 작업 → 종료)를 네트워크 캡처 하에 실행, 외부 목적지 접속 0 을 CI 게이트로. M1 부터 pi 시나리오로 시작해 M2 에서 3종 전체로 확장. M3부터 사내 self-hosted `release-nfr` 필수 게이트가 이를 실행한다.

## NFR-2 LLM 트래픽 게이트웨이 경유 (M)

- **정의**: 모델 추론 호출의 목적지는 게이트웨이가 유일하다.
- **검증**: NFR-1 캡처에서 LLM API 패턴 트래픽의 목적지 분석 + FR-2.5 기동 시 설정 검사.

## NFR-3 로컬 한정 노출 (M)

- **정의**: 데몬은 127.0.0.1 만 바인드. 렌더러-데몬 WebSocket 은 세션 토큰으로 인증 (같은 PC 의 타 프로세스 접속 방지).
- **검증**: 바인드 주소 검사 + 외부 인터페이스 포트 스캔 + 무토큰 접속 거부 테스트.

## NFR-4 라이선스 준수 (M)

- **정의**: ① paseo(AGPL-3.0) 코드 미사용 — 패턴·인터페이스만 분석 문서를 매개로 참고(clean-room). ② 동봉물(MIT/Apache 2.0) 고지 의무 이행 (FR-4.5).
- **검증**: `npm run audit:cleanroom` (M3 3.3.2 — paseo 참조 경계·copyleft 의존성·고지 완전성·고지 정합성 4종) + 코드 리뷰 체크리스트의 "paseo 소스 직접 참조 금지" 항목. 검사 범위와 한계는 [clean-room 검수 기록](../reference/clean-room-audit.md). 유사도 검사 도구 도입은 선택.

## NFR-5 호환성 견고성 (M)

- **정의**: ① 어댑터는 관대한 파싱(미지 필드·이벤트 보존 통과) + 하네스 버전 검증(FR-1.8). ② 데몬-렌더러 프로토콜은 와이어 버전 고정 + capability 협상으로 진화, 모든 호환 코드는 `COMPAT(name): remove after <date>` 태그.
- **검증**: 어댑터 계약 테스트(mock 하네스 포함), 미지 이벤트 주입 테스트, COMPAT 태그 만료 스캔(`npm run audit:compat`)을 매주 및 PR마다 실행한다.

## NFR-6 스트리밍 체감 (S)

- **정의**: 하네스 이벤트 발생 → UI 표시까지 데몬·렌더러 구간에서 인위적 버퍼링 없음. 목표 수치(예: 구간 지연 p95 < 100ms)는 M0 설계에서 확정.
- **주의**: 게이트웨이의 SSE 중계 품질(버퍼링 여부)은 우리 통제 밖 — M0 실측으로 조기 확인 (로드맵 리스크 항목).
- **검증**: E2E 지연 측정 하네스(mock 포함)로 M1 수용 테스트에 포함.

## NFR-7 토큰 절약 기본값 (S)

- **정의**: 같은 작업을 여러 하네스에 중복 실행하도록 유도하는 기능(브로드캐스트 실행 등)을 제공하지 않는다. 사용량 가시화(FR-3.7)로 예산 인지를 보조한다.
- **검증**: 기능 스코프 리뷰 (신규 기능 추가 시 체크 항목).

## NFR-8 설치 무결성·원자성 (M)

- **정의**: ① 번들 구성물은 manifest 체크섬으로 검증(FR-4.2.1). ② 설치·업데이트 중 어느 단계에서 실패해도 기존 설치본과 사용자 데이터는 손상되지 않는다 — 심링크 전환 전까지 기존 상태 불변(FR-4.3.3).
- **검증**: 설치 스크립트 테스트에 단계별 중단 주입(디스크 부족·권한 오류 모사) 포함, 롤백 시나리오(FR-4.4.2) 검증.

## NFR-9 플랫폼 일관성 (S — 신규)

- **정의**: 3 OS 에서 기능 동작·단축키·경로 처리(심링크 vs junction, 홈 경로)가 문서화된 차이 외에는 동일하다.
- **검증**: M2 의 3 하네스 × 3 OS 스모크 매트릭스에 기능 체크리스트 포함.
