# M6 — 워크스페이스 캔버스 (세부 계획 · WBS)

- 문서 목적: [ROADMAP](../ROADMAP.md) M6 의 세부 계획. 워크스페이스를 대화창에서 **작업 캔버스**로 확장한다 (paseo 도입 웨이브 B).
- 상태: draft (v1, 2026-08-30 — 도입 계획 승인, WBS 는 M5 완료 후 재확정)
- 최종 수정일: 2026-08-30
- 진입 조건: M5 완료 (워크스페이스가 탭 타깃의 소유자이므로 선행 필수)
- 완료 기준: 터미널·파일·diff 탭이 세션 탭과 동등하게 배치·복원되고, 워크스페이스 스크립트를 실행할 수 있다
- 근거: [paseo 서비스 구성 분석 §4 웨이브 B](../reference/paseo-service-inventory.md), [FR-8](../requirements/fr8-workbench.md)
