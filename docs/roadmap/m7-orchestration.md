# M7 — 오케스트레이션 · 자동화 (세부 계획 · WBS)

- 문서 목적: [ROADMAP](../ROADMAP.md) M7 의 세부 계획. 세션을 위임·감시 가능한 작업 단위로 만든다 (paseo 도입 웨이브 C).
- 상태: draft (v1.5, 2026-08-31 — **7.2.2 툴 카탈로그 확정**. v1.4: WP 7.1 완료(주의 상태 1급화 7.1.1~7.1.3). v1.3: 7.2.0a·7.2.0b 완료로 WP 7.2 선행 전부 해소. v1.2: 7.2.0a 격리 누수 봉쇄. v1.1: 7.2.1 실측 완료로 WP 7.2 경로 확정 + 선행 과제 신설. 나머지 WBS 는 착수 시 재확정)
- 최종 수정일: 2026-08-31
- 진입 조건: M5 완료 (세션 귀속·워크스페이스 필요). M6 는 UI 트랙에만 선행
- 완료 기준: 주의 상태가 데몬 정본으로 동작 + 세션이 세션을 위임·회수 + CLI 로 세션 조작 자동화 가능
- 근거: [paseo 서비스 구성 분석 §4 웨이브 C](../reference/paseo-service-inventory.md), [FR-9](../requirements/fr9-orchestration.md), [하네스 MCP 지원 실측](../reference/harness-mcp-support.md), [역방향 툴 카탈로그](../design/reverse-tool-catalog.md)
- 관계: 조직 공용 **스킬/MCP 정본 번들은 M4 T1** 이 담당한다. 이 마일스톤은 그 위에서 *역방향 툴 노출*만 다룬다.
