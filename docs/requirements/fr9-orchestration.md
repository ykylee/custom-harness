# FR-9 상세 — 오케스트레이션 · 주의 상태 · 자동화 표면

- 문서 목적: [REQUIREMENTS](../REQUIREMENTS.md) FR-9 그룹의 상세 요구사항. 세션을 **위임·감시 가능한 작업 단위**로 만든다.
- 상태: draft (v1, 2026-08-30 — paseo 서비스 분석 승인에 따른 신설)
- 최종 수정일: 2026-08-30
- 근거 문서: [paseo 서비스 구성 분석 §1.7·1.10·1.14·1.17](../reference/paseo-service-inventory.md)
- 주 단계: M7 (스킬/MCP 정본 번들은 M4 T1 이 담당 — 중복 정의하지 않는다)

## FR-9.1 주의(attention) 상태 1급화 (M, M7)

- 세션 레코드에 `requiresAttention` / `attentionReason`(`finished` | `error` | `permission`) / `attentionTimestamp` 를 **영속 필드**로 둔다. UI 파생값이 아니다.
- 데몬의 단일 정책 모듈이 이벤트에서 주의 상태를 계산하고, 상태 변화를 이벤트로 발행한다.
- 사이드바 버킷·트레이 배지·OS 알림·자동 승인 정책이 모두 이 단일 상태를 소비한다(현재 렌더러 로컬 계산에서 이관).
- 클라이언트가 없는 동안 발생한 주의 상태는 재접속 시 그대로 조회된다.

## FR-9.2 역방향 툴 카탈로그 (S, M7)

- 데몬이 자신의 기능(세션 생성·프롬프트 전송·상태 조회·중단·워크스페이스 조회·터미널 조작)을 **툴 카탈로그 정본**으로 정의한다.
- 노출 경로는 MCP 를 **폴백 어댑터**로 둔다: 네이티브 툴 등록을 지원하는 하네스는 직접 등록하고, 그렇지 않으면 MCP 서버로 노출한다. 지원 여부는 capability 플래그로 협상한다.
- 노출은 기본 off, 세션 생성 시 명시적 opt-in. 자기 자신을 재귀 생성하는 경로에는 깊이·개수 상한을 둔다.
- 선행 실측: 1차 하네스 3종의 MCP 지원 여부(pi 0.84.1 미지원 확인, omp·grok 미실측).

## FR-9.3 서브에이전트 (위임) (S, M7)

- 세션이 다른 세션을 자식으로 생성하고, 완료를 기다리거나 결과를 회수할 수 있다. 부모-자식 관계는 세션 레코드의 라벨로 표현한다.
- 자식 세션은 1급 세션이다 — 탭으로 열어 직접 대화할 수 있다.
- UI 는 부모 세션 화면에서 자식들의 상태를 한 줄 트랙으로 보여준다. 형제 세션(같은 워크스페이스의 독립 세션)은 탭/페인으로, 부모-자식은 트랙으로 구분한다.
- **토큰 제약 고려**: 팬아웃 개수 상한과 사용량 합산 표시를 필수로 한다.
- PURPOSE 의 제외 항목("크로스 하네스 중복 실행")과 구분한다 — 같은 작업의 중복 실행이 아니라 작업 분할·위임이다.

## FR-9.4 검색 · 커맨드 팔레트 (S, M7)

- 세션 타임라인 전문 검색(워크스페이스·기간·하네스 필터).
- 키보드 단축키로 여는 커맨드 팔레트: 세션·워크스페이스·파일·명령을 한 입력창에서 찾아 실행.

## FR-9.5 세션 제목 자동 생성 (C, M7)

- 첫 프롬프트로 세션 제목을 생성한다. **기본은 비 LLM 휴리스틱**(앞 문장 요약)이며, LLM 사용은 설정에서 opt-in 이고 사용 모델을 지정한다(NFR 토큰 절약).

## FR-9.6 CLI 자동화 표면 확장 (S, M7)

- 기존 데몬 제어(FR-5)에 더해 세션·워크스페이스 조작을 추가한다: 세션 생성·목록·프롬프트 전송·출력 스트리밍·중단·승인 응답, 워크스페이스 목록·생성·아카이브.
- 모든 명령에 기계 판독 출력(JSON) 옵션을 둔다 — 스크립트 조합이 자동화의 1급 경로다.
- FR-5.4 의 "에이전트 조작 범위 외" 제한은 이 항목의 승인으로 해제된다.

## FR-9.7 범위 제한 (보류)

- cron 스케줄·heartbeat, 플러그인 SDK 는 보류. 필요가 확인되면 별도 트랙으로 편입한다.
