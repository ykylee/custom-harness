# FR-3 상세 — UI (데스크톱 앱)

- 문서 목적: [REQUIREMENTS](../REQUIREMENTS.md) FR-3 그룹의 상세 요구사항. Electron 셸 + React 렌더러 데스크톱 앱.
- 상태: approved (v1.1, 2026-09-03 사용자 승인 — 트레이 상주 제거)
- 최종 수정일: 2026-09-03
- 근거 문서: [UI 형태 논의](../design/ui-form.md), [paseo 분석 §4](../reference/paseo-analysis.md)

## FR-3.1 세션 생성 (M, M1)

- FR-3.1.1 새 세션 생성 시 하네스 선택(가용 하네스는 어댑터 `isAvailable` 결과 + capability 기반 표시), 작업 디렉토리 선택(네이티브 폴더 픽커 + 최근 목록), 모델 선택(FR-2.4, 기본값 사전 구성)을 제공한다.
- FR-3.1.2 세션 생성 실패(하네스 기동 실패, 게이트웨이 연결 불가)는 원인별 안내와 함께 표출한다.

## FR-3.2 대화 뷰 (M, M1)

- FR-3.2.1 스트리밍 텍스트 렌더링: `message_delta` 를 지연 체감 없이 표시 (NFR-6). 마크다운 렌더 + 코드 블록 구문 강조.
- FR-3.2.2 사고 과정(`reasoning_delta`)은 접힘 기본값으로 구분 표시.
- FR-3.2.3 툴 실행 카드: FR-1.2.5 분류별 요약 표시(shell: 명령·출력, edit/write: 파일 경로 + diff 뷰, read/search: 대상 요약). 진행 중/완료/실패 상태 반영.
- FR-3.2.4 턴 상태 표시: 실행 중 인디케이터, 실패 시 에러 상세, 중단 버튼(FR-1.6).
- FR-3.2.5 스크롤: 스트리밍 중 자동 추적 + 사용자가 위로 스크롤하면 추적 해제(새 메시지 배지).
- FR-3.2.6 프롬프트 컴포저: 멀티라인 입력, 실행 중 입력 큐잉 또는 비활성(M0 설계에서 결정), 파일 경로 첨부(S, M2).

## FR-3.3 멀티 세션 (M, M2)

- FR-3.3.1 사이드바 세션 목록: 상태 버킷(실행 중 / 승인 대기 / 완료 / 에러 / 유휴)별 그룹핑, 세션별 하네스 아이콘·작업 디렉토리 표시.
- FR-3.3.2 탭 + 분할 페인: 세션을 탭으로 열고, 화면을 수직/수평 분할해 여러 세션 동시 표시.
- FR-3.3.3 탭 닫기는 세션 종료가 아니다 — 세션은 데몬에 유지되고 목록에서 재열람 가능. 세션 종료/보관은 명시적 조작.
- FR-3.3.4 키보드 내비게이션: 세션 전환·새 세션·중단 단축키 (구체 바인딩은 설계에서).

## FR-3.4 승인 UI (M, M1)

- FR-3.4.1 승인 요청을 대화 뷰 인라인 카드로 표시: 종류(shell 실행/파일 쓰기/기타), 대상 요약, 원본 상세(펼침), 허용/거부 버튼.
- FR-3.4.2 백그라운드 세션(비활성 탭)의 승인 요청은 사이드바 배지 + 알림(FR-3.5)으로 유도.
- FR-3.4.3 "이 세션에서 항상 허용"(세션 한정 자동 승인, FR-1.5 opt-in)은 위험 고지와 함께 제공 (S, M2).

## FR-3.5 앱 종료·알림 (S, M2)

- FR-3.5.1 창을 닫으면 앱을 종료하고, 앱 소유 데몬·세션도 함께 종료한다. 트레이 상주는 제공하지 않는다.
- FR-3.5.2 네이티브 알림: 승인 대기 발생, 턴 완료/실패 시. 알림 클릭 → 해당 세션 포커스. 알림 on/off 설정 제공.

## FR-3.6 설정 화면 (M, M1: 키 / M2: 나머지)

- FR-3.6.1 게이트웨이 API 키 등록·변경·삭제 (FR-2.3).
- FR-3.6.2 하네스별 기본 모델 선택 (FR-2.4).
- FR-3.6.3 하네스 상태 패널: 동봉 버전, 실행 파일 경로, 버전 검증 결과(FR-1.8), 가용성.
- FR-3.6.4 알림 설정(FR-3.5.2), 자동 승인 정책 표시.

## FR-3.7 토큰 사용량 표시 (S, M2)

- `usage_updated` 이벤트 기반 세션별 누적·턴별 토큰 표시. 토큰 제약 환경(CONCEPT §5)에서 사용자가 예산을 인지하도록 세션 목록에도 요약 노출.

## FR-3.8 온보딩 (M, M1)

- 최초 실행 마법사: ① 게이트웨이 API 키 입력 → ② 연결 확인(테스트 호출, 실패 시 안내) → ③ 기본 하네스·모델 확인 → 완료 후 바로 세션 생성 가능 상태. zero-config 의 사용자 접점 — 이 단계 외 설정 없이 첫 세션이 성립해야 한다.
