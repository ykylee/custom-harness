# M1 — 코어 수직 절단 / MVP (세부 계획 · WBS)

- 문서 목적: [ROADMAP](../ROADMAP.md) M1 의 세부 계획. "pi 하나로 끝까지" — 설치 → 온보딩 → pi 세션으로 실제 코딩 작업 1건.
- 상태: approved (v1, 2026-08-25 사용자 승인)
- 최종 수정일: 2026-08-25
- 진입 조건 (2026-08-25 개정): M0 완료 — 어댑터 계약·프로토콜·데몬 설계 승인. **게이트웨이 실측(구 0.5.4)은 M1 으로 이월됨**: 개발은 목 게이트웨이로 진행하고, **실 게이트웨이 실측 통과가 M1 수용 테스트의 선행 조건**이다 (사용자 승인).
- 완료 기준(수용 테스트): [이월] 실 게이트웨이 실측(C-1) 완료 → 폐쇄망 모사 환경에서 macOS arm64 아카이브 설치 → 온보딩(키 입력·연결 확인) → pi 세션 생성 → 실제 코드 수정 작업 1건 완료(승인 1회 이상 포함) → 데몬 재시작 후 세션 재개 → 전 과정 외부 네트워크 요청 0

## 순서·병렬 트랙

```
1.1 ─→ 1.2 ─→ 1.3 ─→ ┐
        ├─→ 1.4      ├─→ 1.7
1.1 ─→ 1.5 ──────────┤
1.2.1 → 1.6 ─────────┘
```

- 1.3(어댑터)과 1.5(렌더러)는 protocol 확정(1.1.2) 후 병렬 진행 가능 — mock 하네스(1.3.4)를 앞당기면 렌더러가 어댑터 완성을 기다리지 않는다.

## 리스크

- 대화 뷰(1.5.3)와 세션 매니저(1.2.2)가 규모 L — 여기서 지연 시 1.5.4~5 범위를 최소 표시로 줄여 수용 시나리오 우선.
- 게이트웨이 스트리밍 문제가 M0 실측을 통과했어도 실 워크로드에서 재발 가능 → 1.7.3 에 스트리밍 체감 확인 포함.
