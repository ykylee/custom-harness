# M7 — 오케스트레이션 · 자동화 (세부 계획 · WBS)

- 문서 목적: [ROADMAP](../ROADMAP.md) M7 의 세부 계획. 세션을 위임·감시 가능한 작업 단위로 만든다 (paseo 도입 웨이브 C).
- 상태: draft (v1, 2026-08-30 — 도입 계획 승인, WBS 는 M6 완료 후 재확정)
- 최종 수정일: 2026-08-30
- 진입 조건: M5 완료 (세션 귀속·워크스페이스 필요). M6 는 UI 트랙에만 선행
- 완료 기준: 주의 상태가 데몬 정본으로 동작 + 세션이 세션을 위임·회수 + CLI 로 세션 조작 자동화 가능
- 근거: [paseo 서비스 구성 분석 §4 웨이브 C](../reference/paseo-service-inventory.md), [FR-9](../requirements/fr9-orchestration.md)
- 관계: 조직 공용 **스킬/MCP 정본 번들은 M4 T1** 이 담당한다. 이 마일스톤은 그 위에서 *역방향 툴 노출*만 다룬다.
